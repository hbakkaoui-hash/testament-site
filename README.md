# Testament — site de démonstration

Site public du prototype **Testament** : messages posthumes délivrés après un décès
présumé par un protocole de preuve de vie.

**Ce dépôt ne contient que les fichiers servis au navigateur.** Le code source
complet, la spécification fonctionnelle, la suite de tests et l’outillage vivent
dans un dépôt privé.

Le prototype fonctionne entièrement dans le navigateur : les données restent en
mémoire locale, rien n’est transmis, aucun message n’est réellement délivré.
